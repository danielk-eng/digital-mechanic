# Стоимость эксплуатации и внедрения

## Методика
Замер на стенде (`GET /api/usage` и журнал `var/app.log.jsonl`), 26.11.2026, модель `deepseek/deepseek-v4.1-flash-1017-free`
через TokenRouter, `LLM_THINKING=off`. 53 хода агента (сценарии С1–С4, контрольные вопросы, 6 языков):

| Показатель | Значение |
|---|---|
| Токенов на ход агента, медиана / среднее / p90 | 9,9 тыс. / 14,1 тыс. / 24,6 тыс. |
| Доля входных токенов | ≈ 96 % (фрагменты руководства и история), выход ≈ 0,4 тыс. на ход |
| Время ответа, медиана / p90 | 14 с / 42 с (самое долгое — черновик заявки) |
| Сбой записи, норма, «готово» в ремонте, подтверждение заявки | 0 токенов — решает код |

**Типовая проверка ТС** = объяснение вердикта + 2 вопроса + заявка ≈ 4 хода ≈ 40 тыс. входных и 1,6 тыс. выходных токенов.

## Парк из 50 ТС (как в данных хакатона)
Проверка раз в неделю → 2 600 проверок в год.

| Статья | В месяц | В год |
|---|---|---|
| LLM + голос (DeepSeek-класс) | ≈ 330 ₽ | ≈ 4 тыс. ₽ |
| То же на российской LLM | ≈ 2–4 тыс. ₽ | ≈ 20–45 тыс. ₽ |
| Сервер 2 vCPU / 4 ГБ в РФ (приложение + SQLite, без GPU) | ≈ 1,5–2,5 тыс. ₽ | ≈ 18–30 тыс. ₽ |
| **Итого** | **≈ 2–6 тыс. ₽** | **≈ 25–75 тыс. ₽** |

Локальный вариант без внешних API (сервер с GPU для open-source LLM и whisper) имеет смысл от нескольких сотен ТС
или при запрете внешних сервисов: ≈ 40–80 тыс. ₽/мес аренды GPU, переменные расходы ≈ 0.

## Эффект (для сравнения)
Один внеплановый сход ТС с линии — эвакуация, простой и ремонт — обычно стоит десятки–сотни тысяч рублей. Годовая
эксплуатация агента на парк из 50 ТС сопоставима с одним часом работы эвакуатора или парой нормо-часов моториста;
окупается, если в год предотвращён хотя бы один отказ или сокращена дефектовка за счёт точного порядка проверки.

## Как уменьшить расход
Кэш фрагментов (повторные вопросы по той же машине), меньше `k` в поиске, история диалога не длиннее 12 сообщений
(уже так), короткие ответы (3–8 строк, уже в промпте). Модель меняется одной переменной `LLM_MODEL`.
