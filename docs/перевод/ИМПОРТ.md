# Как загрузить переводы в приложение

1. Заполните поля `text_<язык>` в `data/*.jsonl` (см. ПРОМТЫ.md). Глоссарий `glossary_ru.csv`: столбцы языков, статус «проверено» после проверки.
2. Пробный прогон без записи:
   `cd <репозиторий app> && PYTHONPATH=src python scripts/import_translations.py <папка перевод> --app . --langs uz --dry-run`
   Отчёт `import_report.md` появится в папке перевода: сколько принято и что отклонено, с причиной (потеряны числа, коды, письменность и т. п.).
3. Исправьте отклонённые записи и повторите. Ключ `--force` берёт и спорные записи; используйте его только после ручной проверки.
4. Боевой прогон (без `--dry-run`) пишет:
   - `data/i18n/pages_<язык>.jsonl.gz`: переведённые страницы руководств. При старте приложение добавляет их в поиск. Вопрос на узбекском находит страницу по переводу, а ответ ссылается на русскую страницу-оригинал (документ и номер страницы те же);
   - `data/i18n/strings_<язык>.json`: строки приложения, шаги, заявки, коды. Переводчик «на лету» берёт их вместо машинного перевода;
   - `data/i18n/glossary.json`: термины для машинного перевода;
   - `src/digital_mechanic/web/static/i18n.json`: строки интерфейса.
5. Проверка: `PYTHONPATH=src:vendor/neurodvs_mock python -m pytest -q`, затем перезапуск сервиса. В `/api/translate/stats` видно, сколько страниц и строк загружено по каждому языку.
6. В приложении кнопка «Оригинал на русском» в окне страницы всегда показывает исходный текст.
