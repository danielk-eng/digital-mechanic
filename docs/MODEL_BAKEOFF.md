# Сравнение моделей Cloud.ru с текущими (26.11.2026)

Взяты только модели из списка V: GigaChat-4-708B-A41, whisper-large-v3, GigaASR, bge-m3, Qwen3-Embedding-0.6B, Giga-Embeddings-instruct-480M, bge-reranker-v2-m3, Qwen3-Reranker-0.6B. Другие модели не вызывались. Цены взяты из каталога `/v1/models` в ₽ за 1 млн токенов.

**Затраты на сравнение — около 3,4 ₽:**
- эмбеддинги — 3,0 ₽;
- реранкеры — 0,36 ₽;
- распознавание речи — копейки;
- GigaChat-4-708B бесплатен.

## Языковая модель

Наборы вопросов:
- qset — 18 вопросов с ответом и 4 «нет данных»;
- персоны — 3 персоны × 4 вопроса.

Текущая модель тоже бесплатная, через TokenRouter. Стиль оценивал один судья (текущая модель) для обоих вариантов.

| | Текущая | GigaChat-4-708B (Cloud.ru, РФ) |
|---|---|---|
| Цена | 0 | 0 |
| Верная цитата (cite_acc) | **0.944** | 0.889 (не прошёл q21) |
| Точность цитат (cite_prec) | **0.89** | 0.81 |
| Отказ без данных (refuse_acc) | 0.75 | 0.75 |
| Задержка qset, медиана / p90 | **11.4 / 28.0 с** | 38.1 / 82.0 с |
| Задержка на персонах, медиана | **11.3 с** | 26.2 с |
| Стиль: ветеран / самоучка / студент | 3.75 / 4.5 / 4.0 | **5.0 / 4.5 / 4.25** |
| Паритет фактов (страницы и числа, Jaccard) | 1.0 на всех 4 вопросах | 1.0 на всех 4 вопросах |
| Токенов на ответ, медиана | 910 | 1936 (с рассуждением) |

Итог по GigaChat:
- По стилю он лучше.
- Он в 2,5–3,5 раза медленнее и не укладывается в требование демо (≲10 с на ответ).
- Цитаты на один вопрос хуже.
- Рассуждение не отключается: пробовали `reasoning_effort`, `chat_template_kwargs.enable_thinking`, `thinking`.

**Решение:** основной остаётся текущая модель (`LLM_PRIMARY=tokenrouter`). GigaChat-4 — резерв при её сбое. `LLM_PRIMARY=auto` включает строгий режим 152-ФЗ: для РФ и стран из `CLOUDRU_COUNTRIES` первым идёт Cloud.ru.

18 вопросов qset с ответом, руководства двигателей.

| BM25@30 → Qwen3-Reranker-0.6B | 0.50 | 0.83 | 0.83 | 0.645 | ≈0,016 ₽ за запрос |

«Цена за индекс» — разовая: эмбеддинги 1743 страниц, это 0,5–0,8 млн токенов. Сам запрос эмбеддинга занимает от 0,3 с.

Итог по поиску:
- Лучший вариант — гибрид с Giga-Embeddings.
- Но он выигрывает всего один вопрос на hit@3 (+0,014 MRR). На 18 вопросах это шум.
- Реранкеры качество ухудшают.

**Решение:** оставляем BM25 — без внешнего вызова, задержки и затрат. Гибрид с Giga-Embeddings — запасной вариант, если вопросов станет больше и BM25 начнёт промахиваться.

## Распознавание речи

Проверено через путь приложения `voice.cloudru_stt` (тот же промпт и постобработка).

| Язык | Текущий путь | WER, задержка | Cloud.ru | WER, задержка |
|---|---|---|---|---|
| ru (3 фразы) | локальный whisper / Deepgram | 0.00, 14.2 с / 0.04, 0.9 с | **GigaASR** | **0.00, 1.1 с** |
| ru | | | whisper-large-v3 | 0.00, 1.1 с |
| kk | локальный whisper | 0.29, 11.7 с | **whisper-large-v3** | **0.00, 0.9 с** |
| hi | Deepgram | 0.33, 1.4 с | whisper-large-v3 | 0.00, 1.1 с |
| vi | Deepgram | 0.00, 1.2 с | whisper-large-v3 | 0.00, 1.9 с |
| uz (16 записей, 2 голоса) | navai на стенде / Deepgram | **0.171**, 6.9 с / **0.133**, 2.2 с | whisper-large-v3 | 0.956, 1.1 с |

**Решение:**
- Для людей из РФ-региона первым идёт Cloud.ru: GigaASR для ru, whisper-large-v3 для kk и других языков.
- Узбекский на Cloud.ru не отправляется (`CLOUDRU_STT_SKIP`): для него остаются navai и Deepgram.
- Если закон страны требует хранить данные внутри неё (KZ, UZ), первым идёт whisper на стенде, Cloud.ru — вторым.
- Для остальных стран (IN, VN) Cloud.ru не используется.
- Цена — доли копейки за фразу.
