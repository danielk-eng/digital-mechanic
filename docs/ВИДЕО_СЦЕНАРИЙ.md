# Видео: дополнительные сцены по ответам организаторов (27.11)

Основной сценарий — [ВИДЕО_СЦЕНАРИЙ_3МИН.md](ВИДЕО_СЦЕНАРИЙ_3МИН.md). Эти три сцены показывают правила из ответов организаторов 26.11 (`организаторы: «не пишите обратитесь к специалисту»`, «0,48 — перезаписать», «ремонт на несколько дней»). Каждая укладывается в 20–25 с; при монтаже ставить после сцены с вердиктом.

Все машины и сессии — из данных хакатона, на стенде воспроизводятся как есть. Поведение закреплено автотестами `tests/test_organizer_rules.py`.

| Кадр | Действие | Голос за кадром |
|---|---|---|
| Телефон, механик Сидоров П. (PIN 3002), машина с отклонением | Вопрос: «Какой момент затяжки болтов турбокомпрессора?» | «Если в руководстве этого двигателя нужной страницы нет…» |

## Подготовка стенда перед записью
- Сцена В: начать ремонт заранее под Ивановым А., чтобы отметка была «вчерашней» (или показать как есть — дата видна).
- Проверить, что в ответах нет фразы «обратитесь к специалисту»: `git grep -n "обратитесь к специалисту" src` — только строка-фильтр в `answer_post.py`.
