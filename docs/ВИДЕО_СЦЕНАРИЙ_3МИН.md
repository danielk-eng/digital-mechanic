# Сценарий видео, 3 минуты

Один дубль без монтажа. Ведущий: V. Главный экран: ноутбук 1280×800, панель главного специалиста. Фрагмент механика показываем на телефоне (390×844 или реальный телефон через scrcpy).
Подготовка: стенд deb с детерминированными демо-данными (последняя проверка M851TA178, S-0122, 22.11 16:50 МСК, F11). Включён микрофон, в браузере есть русский голос синтеза речи. Перед записью один прогревочный прогон.
Репетиция: `audit/demo_e2e.py`, голос подаётся через фальшивый микрофон Chrome (`audit/demo_in/q1.wav`, `q2.wav`). Машинное время всех шагов 51 с (`audit/after/demo_timing.json`). Остальное время занимают реплики ведущего и озвучка ответов.
Голос: распознавание речи (Deepgram, у РФ local-first), озвучка в браузере. Если сеть подвела, ведущий говорит ту же фразу текстом в поле ввода, ответ будет тем же.

## Если что-то пошло не так

- Распознавание не сработало: ведущий нажимает кнопку «Создать и назначить» под ответом (тот же сценарий).
- Озвучка молчит: ответ на экране полный, ведущий читает подпись.
- На стенде уже есть TKT-0001 после репетиции: номер будет следующим, остальное то же (последняя проверка, повтор и похожий случай берутся из демо-истории и не меняются).
