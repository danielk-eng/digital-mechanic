Как это устроено:
- файлы лежат на диске и на стендах, но в git их нет (`.gitignore`: `data/index/*.jsonl.gz`);
- деплой берёт их с диска: `scripts/stand_bundle.sh` (deb: HEAD + индексы) и `scripts/vercel_bundle.sh`;
- свежий клон: `python scripts/fetch_manuals.py` — скачивает каждое руководство из первоисточника по `data/manuals_manifest.json`, сверяет sha256 и собирает оба индекса и картинки страниц локально (подробнее ниже);
- тесты без индекса: идут только юнит-тесты, не требующие страниц (18). Остальные пропускаются с понятной причиной.

Проверка перед push: `git ls-files | grep -E "jsonl.gz|\.pdf|extra/images"` должен быть пуст.

## Руководства: манифест вместо копий (решение 26.11, 12:04)
Зашифрованных копий в репозитории нет. В репозитории — только код и `data/manuals_manifest.json`: для каждого документа `id`, `kind` (engine / vehicle), официальный или публичный источник (`url`, для руководств двигателей из материалов задачи — папка Заказчика на Яндекс Диске `yandex`), `sha256`, число страниц, `license` (условия, как они написаны на титуле или на сайте), `redistributable` (у всех false), для «соседних» моделей — `sibling` с пояснением.

`scripts/fetch_manuals.py`:
- качает PDF (двигатели → `data/manuals/`, автомобили → `data/extra/pdf/`), сверяет sha256; если файл у источника поменялся (новое издание), останавливается — нужно перепроверить условия и обновить манифест (`--accept-changed`);
- собирает `data/index/pages.jsonl.gz` (руководства двигателей, `ingest/pages.py`) и `data/index/extra_pages.jsonl.gz` (руководства на автомобили: слой текста PDF, сканы без текста — OCR tesseract rus, если он установлен; текст в cp1251 перекодируется);
- рендерит картинки страниц автомобильных руководств в `data/extra/images/<slug>/page-NNN.jpg` (страницы двигателей рендерятся из PDF по запросу);
- `--only ID1,ID2` — пересобрать только эти документы (остальные страницы индекса остаются), `--no-images`, `--ocr never`, `--download-only`.

Стенды (deb, Vercel) держат полные руководства и индексы; репозиторий — код и манифест. OCR-текст сканов при повторной сборке может немного отличаться от текста на стенде (другая версия tesseract).
