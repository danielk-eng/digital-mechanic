# Цифровой механик — описание продукта (1 стр.)
*Структура — по разделам из регламента сдачи; сверить с шаблоном в кабинете перед загрузкой.*

**Задача.** Механику на посту ТО нужен понятный ответ вместо JSON ML-модели «НейроДВС»: что, вероятно, не так, чем грозит, что и как проверить по руководству на двигатель именно этой машины, и готовая заявка на дефектовку в ТОиР. Главному механику — сводка по парку и приоритеты.

**Подход и архитектура.** Веб-чат (адаптивный, телефон) → FastAPI → агент на LLM с вызовом инструментов. Агент сам выбирает инструмент: результат проверки (ML-сервис), поиск по руководствам, история машины, черновик заявки, пошаговый ремонт, справка по автомобилю. Всё, что влияет на безопасность, решает код: при сбое записи диагноз не ставится и заявка запрещена; приоритет заявки считается по таблице критичности узлов и оценкам ML с обоснованием; при низкой уверенности — сначала осмотр узла; в ТОиР заявка уходит только после «Подтвердить». Поиск — BM25 по страницам PDF с фильтром по модели двигателя до ранжирования, поэтому норматив чужого двигателя в ответ попасть не может. Каждое число ответа сверяется со страницами, которые агент открыл; неподтверждённое переписывается или вырезается. Адреса ML и ТОиР — в `.env`.

**Стек и модели.** Python 3.12, FastAPI, Pydantic, SQLite, BM25 (snowball-стемминг), poppler (текст и картинки страниц). LLM: `deepseek/deepseek-v4.1-flash-1017-free` через OpenAI-совместимый API TokenRouter (меняется одной переменной; работает с YandexGPT/GigaChat/локальными моделями). Голос: локальный faster-whisper large-v3-turbo (CPU, звук не покидает сервер), запасные — Deepgram nova-3 и распознавание браузера; озвучка — Silero. GPU и эмбеддинги не нужны. Docker compose: заглушки Заказчика + приложение.

**Принцип работы.** 1) Механик входит (согласие на ПДн), выбирает машину вручную или фото госномера. 2) «Получить результат диагностики» → вердикт со светофором за 10 секунд: норма / отклонение / сбой записи. 3) При отклонении агент находит страницы руководства этого двигателя и объясняет: наблюдения → гипотезы → проверки (допуски, порядок) → ремонт → источник → ограничения. Страница открывается по клику. 4) Вопросы текстом или голосом на 6 языках (ru, uz, tg, kk, hi, vi); нет данных — честное «в руководстве нет» и дефектовка. 5) «Создать заявку» → черновик строго по контракту ТОиР → «Подтвердить» → ticket_id. 6) «Начать ремонт» → шаги из руководства, «готово» / «повтори» голосом — руки свободны. 7) Главный механик: норма / внимание / карантин, приоритетный список, график anomaly_score, история, заявки, ремонты, журнал запросов.

**Сделано / не сделано.** Сделано: F1–F7, B1–B3, сценарии С1–С4; голос, фото, 6 языков, режимы «новичок/опытный», пошаговый ремонт, журнал и выгрузка, 152-ФЗ (согласие, маскирование ПДн до LLM, срок хранения, удаление своих данных), docker compose, 63 автотеста. Сверх ТЗ (по разбору аналогов): блок «Важно из руководства» дословно со страницы, просмотр цитаты (выжимка → весь раздел → страница PDF), поиск по разделам, «Понял как» для жаргона, другие варианты и проверка гипотезы, проверенные решения по парку, карточка «К заезду», резюме смены и «Передать главному», акт осмотра по фото, согласование заявок главным, плитки «В ремонте / Ждут согласования / На линии / Простой», печать процедуры, поиск машины по госномеру, субтитры и три темы. Правило везде одно: нет страницы — нет цифры. Не делали по брифингу: поиск и парсинг запчастей, прогнозирование, real-time аудио, 1С, мобильное приложение. Не сделано: фото положения стенда как обязательный шаг (нет записи на хакатоне), OCR картинок-таблиц в PDF.

**Стоимость эксплуатации и внедрения.** Замер: ход агента ≈ 10 тыс. токенов (96 % — фрагменты руководства), проверка ТС ≈ 4 хода ≈ 1,5 ₽ (LLM DeepSeek-класса + голос). Парк 50 ТС, проверка еженедельно: ≈ 25–75 тыс. ₽ в год с сервером в РФ; на российской LLM — до ≈ 75 тыс. ₽. Внедрение до пилота ≈ 20–30 чел.-дней. Расчёт и методика — `docs/ЭКОНОМИКА.md`.

**Наработки и компоненты третьих лиц.** До спринта — только проектирование и каркас контрактов (схемы, политика, фильтр по двигателю), импортирован первым коммитом «Sprint start: import pre-sprint contract skeleton»; остальной код, промпты и индексы созданы в спринте. Библиотеки: FastAPI, Uvicorn, Pydantic, httpx, openai-python, pypdf, PyYAML, snowballstemmer, poppler-utils; faster-whisper, Silero TTS, Tesseract (OCR при сборке базы), опционально Opik. API: TokenRouter (LLM), Deepgram (STT). Заглушки ML/ТОиР и PDF — материалы Заказчика. Доп. справка по автомобилям МАЗ (maz-ptc.ru) и Урал-5557-40 (shop.uralaz.ru, OCR) (руководство КАМАЗ с неофициального зеркала исключено). Код генерировался с помощью ИИ-ассистента разработки (не входит в продукт).
