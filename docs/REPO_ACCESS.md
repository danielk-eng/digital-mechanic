# Закрытый репозиторий для организаторов

Решение сдаётся в **приватный** репозиторий GitHub с доступом для организаторов и жюри. Код и история коммитов — наша интеллектуальная собственность, публично не публикуются.

## Что уходит в репозиторий

- Код, тесты, документация, Docker-конфигурации (облачный и локальный режимы), набор вопросов `eval/qset.json`.
- Вся история коммитов с 26.11.2026 (≈200 коммитов), авторство и даты сохранены.

## Что не уходит никогда

- Секреты: ключи только в `.env` и переменных окружения (`.env` в `.gitignore`). Проверка — `gitleaks` по всей истории.
- Тексты и PDF руководств производителей (ЯМЗ, ЗМЗ, Урал, МАЗ, УАЗ) и их индексы: права на распространение нет. Они живут только на стенде; свежий клон собирает индекс из PDF по `docs/ПУБЛИКАЦИЯ.md`.
- Зеркало КАМАЗ, записи и расшифровки брифингов, материалы заказчика (`materials/`), пользовательские данные (`var/`).

Индексы руководств были в git 26.11 (коммиты 4237dcc…7f76f09). Поэтому в репозиторий пушится **очищенная копия** истории, а не рабочий репозиторий напрямую.

## Как подготовить и выложить

```bash
pip install git-filter-repo                     # + gitleaks: https://github.com/gitleaks/gitleaks/releases
scripts/export_private_repo.sh                  # клон main → ../_work/private-export, вырезает запрещённые пути из всех коммитов, gitleaks
# создать на GitHub приватный репозиторий (владелец — V), затем:
cd ../_work/private-export
git remote add origin git@github.com:<owner>/<repo>.git
git push -u origin main
```

## Доступ

1. GitHub → репозиторий → Settings → Collaborators and teams → Add people.
2. Добавить логины организаторов и жюри с ролью **Read** (видеть код и историю, без права записи).
3. Ссылку на репозиторий и список приглашённых логинов указать в форме сдачи.
4. После подведения итогов — снять доступ там же (Remove).

## Дальнейшие коммиты

Работа продолжается в том же репозитории: каждый коммит после сдачи виден организаторам. Перед каждым push: `gitleaks git --redact .` и `git ls-files | grep -Ei 'pdf|jsonl.gz|kamaz'` — пусто.
