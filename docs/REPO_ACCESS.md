# Публичный репозиторий для сдачи

По памятке организаторов к форме сдачи (27.11) код сдаётся **публичным** репозиторием GitHub с историей коммитов. Репозиторий открыт до подведения итогов.

## Что уходит в репозиторий

- Код, тесты, документация, Docker-конфигурации (облачный и локальный режимы), набор вопросов `eval/qset.json`, калькулятор стоимости (`src/digital_mechanic/web/static/calculator.xlsx`).
- История коммитов с 26.11.2026, авторство и даты сохранены.

## Что не уходит никогда

- Секреты: ключи только в `.env` и переменных окружения (`.env` в `.gitignore`). Проверка — `gitleaks` по всей истории (конфиг `.gitleaks.toml`: стандартные правила; исключён только шаблон `.env.example` с пустыми значениями).
- Тексты, PDF и индексы руководств производителей (ЯМЗ, ЗМЗ, Урал, МАЗ, УАЗ): права на распространение нет. Они живут только на стендах. Свежий клон собирает индекс из PDF первоисточников по `data/manuals_manifest.json` (`docs/ПУБЛИКАЦИЯ.md`).
- Зеркало КАМАЗ, записи и расшифровки брифингов, материалы заказчика (`materials/`), пользовательские данные (`var/`), внутренний журнал работ `STATUS.md`.

Индексы руководств лежали в git 26.11 (коммиты 4237dcc…7f76f09, в том числе f29c03d с текстом руководства КАМАЗ). Поэтому в GitHub пушится **очищенная копия** истории (public-export), а не рабочий репозиторий.

## Как подготовить и выложить

```bash
pip install git-filter-repo                     # + gitleaks: https://github.com/gitleaks/gitleaks/releases
scripts/export_public_repo.sh                   # клон main -> ../_work/public-export; вырезает запрещённые пути из всех коммитов;
                                                # проверяет, что их не осталось; gitleaks по всей истории
# на GitHub: New repository, видимость Public, без README (владелец — V), затем:
cd ../_work/public-export
git remote add origin git@github.com:<owner>/<repo>.git
git push -u origin main
```

Проверка 27.11 06:00 CST: 197 коммитов, 1,9 МБ, gitleaks — «no leaks found»; путей с руководствами, PDF, индексами, КАМАЗ, брифингами, `STATUS.md`, `.env` в истории нет.

## Дальнейшие коммиты

Каждый следующий push — тоже через `scripts/export_public_repo.sh` (история пересобирается детерминированно, хэши совпадают с уже выложенными) или прямым push из рабочего репозитория, если в новых коммитах нет запрещённых путей: `git ls-files | grep -Ei 'pdf|jsonl.gz|kamaz'` и `gitleaks git --redact .` — пусто.
