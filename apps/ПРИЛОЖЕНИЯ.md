# Приложения «Цифровой механик»

Обёртки над живым стендом: интерфейс и языковая матрица подхватываются с сервера без пересборки; пересборка нужна при изменении нативной оболочки, разрешений, версии или адреса по умолчанию. По умолчанию Android открывает mobile shell:
`https://digital-mechanic-iikuznitsa.vercel.app/m`
Windows/Linux открывают desktop shell:
`https://digital-mechanic-iikuznitsa.vercel.app/desktop`
Адрес можно сменить на стенд deb (актуальный временный tunnel — в `../stand/PUBLIC_URL.txt`, когда он запущен)
или на любой другой. Если указать сервер без `/m` или `/desktop`, веб сам выберет shell по ширине экрана.

Сборка: 27.11.2026, 17:57 CST. Версия 1.1.0.
Пакет Android / appId Electron: `ru.iikuznitsa.mechanic`.

Исходники: `apps/` в репозитории. В этой рабочей копии готовые файлы лежат уровнем выше репозитория в `../приложения/`; в пакете сдачи их нужно разместить в папке дополнительных материалов.
Ключ подписи APK в репозиторий не входит.

## Android

1. Скопируйте `DigitalMechanic-1.1.0.apk` на телефон.
2. Откройте файл. Если система спросит — разрешите установку из этого источника.
3. При первом использовании микрофона и камеры Android запросит разрешение. Приложение передаёт его во WebView, только когда страница стенда сама просит доступ к микрофону или камере.
4. `*-debug.apk` подписан тем же ключом, это не стандартный debug-ключ Android Studio.

Сменить адрес сервера:

- долгий тап по иконке приложения → ярлык «Сервер»;
- долгий тап кнопки «Назад» в приложении;
- если стенд недоступен, на экране «Нет связи» кнопка «Адрес сервера»;
- через adb: `adb shell am start -n ru.iikuznitsa.mechanic/.MainActivity --es server_url https://пример/m`.

## Windows

1. Распакуйте `DigitalMechanic-win-1.1.0.zip` в любую папку (например, `C:\Program Files\DigitalMechanic`).
2. Запустите `DigitalMechanic.exe`. Подпись Authenticode нет — SmartScreen может показать предупреждение; «Подробнее» → «Выполнить в любом случае».
3. Меню «Файл → Адрес сервера…» (Ctrl+,). Микрофон и камера разрешаются только для происхождения текущего стенда, не для чужих сайтов.

Другие способы задать адрес (в таком порядке): флаг `--server-url=https://…/desktop`, переменная `MECHANIC_SERVER_URL`, файл `server-url.txt` рядом с `DigitalMechanic.exe`, сохранённый адрес из меню.

## Linux

```bash
chmod +x DigitalMechanic-1.1.0.AppImage
./DigitalMechanic-1.1.0.AppImage
```

Меню и смена адреса — как в Windows. На части дистрибутивов AppImage просит FUSE (`libfuse2`).

## iPhone / iPad

Отдельного IPA в этой сборке нет. На iPhone приложение ставится как PWA: в Safari открыть стенд → «Поделиться» → «На экран "Домой"». Манифест, `apple-touch-icon` и режим `standalone` в вебе уже есть. Микрофон Safari запросит сам. Для принудительного mobile shell можно открыть `/m`.

## Пересборка

Нужны JDK 21, Android SDK (cmdline-tools, platform 35, build-tools 35), Node.js и Pillow для генерации Android-иконок.

```bash
export JAVA_HOME=…/jdk-21
export ANDROID_SDK_ROOT=…/android-sdk
export MECHANIC_KEYSTORE=…/mechanic-release.jks   # не из репозитория
export MECHANIC_KEYSTORE_PASSFILE=…/keystore.pass
apps/scripts/build-android.sh /путь/к/выдаче
apps/scripts/build-desktop.sh /путь/к/выдаче
apps/scripts/verify-apk.sh /путь/к/выдаче/DigitalMechanic-1.1.0.apk
```

Если установлен Wine, `build-desktop.sh` дополнительно соберёт NSIS и portable.exe.
