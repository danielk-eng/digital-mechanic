# Предстартовый каркас контрактов

Это **не** конкурсный прототип. По п. 4.4 Положения и ответам организаторов 19–20.11.2026 код, промпты и поисковый индекс продукта пишутся с 10:00 МСК 26.11.2026.

Здесь только:

- канонические схемы полей, которые организаторы уже опубликовали в чате и сборнике;
- детерминированная политика «не выдумывать» (чтобы не потерять её в спринте);
- пустые интерфейсы инструментов, ingest и поиска;
- макет веб-чата (проектирование разрешено);
- тесты на опубликованные правила.

Официальные FastAPI-заглушки, `vehicles.json`, справочник F01…F14 и шесть PDF придут в архиве на брифинге. Подставляются через адаптеры, этот каркас не выдаёт себя за архив заказчика.

Исследовательский прототип от 16.11 лежит в `/workspace/ik/mechanic`. Если что-то из него войдёт в сдачу, это нужно указать в описании продукта как наработку.

```bash
# после 26.11 10:00 МСК, когда появится официальный архив:
cd app
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export PYTHONPATH="$PWD/src"
python -m pytest
# заглушки заказчика — как в их README, не эти заготовки
```

Секреты только из переменных окружения (см. `.env.example`). В git их не класть.
